# Creacion de cuenta Microsoft Azure
>Paso 1
1.  Ingrese a [Azure for Students](https://azure.microsoft.com/es-es/free/students/ "null")
    
2.  Haga clic en **"Empezar gratis"**.
    
3.  Inicie sesión con su cuenta de estudiante (correo institucional).
    
4.  Complete el registro proporcionando la información solicitada.
    
5.  Una vez creada la cuenta, acceda al portal de Azure en [https://portal.azure.com](https://portal.azure.com "null").
    

###  Renueva tus créditos si no tienes

1.  Ingresa a [Oferta de Microsoft Azure for students Starter](https://azure.microsoft.com/es-es/offers/ms-azr-0144p/ "null")
    
2.  Haga clic en **"Activar"**.
    
3.  Inicie sesión con su cuenta de estudiante (correo institucional).
    
4.  Complete el registro proporcionando la información solicitada.
    
5.  Una vez creada la cuenta, acceda al portal de Azure en [https://portal.azure.com](https://portal.azure.com).
